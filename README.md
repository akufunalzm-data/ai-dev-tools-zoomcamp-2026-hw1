# Shared Household Chores Tool

Homework 1 for the AI Dev Tools Zoomcamp, planned with Codex CLI.

## Purpose

A shared interface for one small household to manage one-time chores without accounts or authentication.

## Approved Features

1. Add and view household members who can be assigned chores.
2. Create and assign a one-time chore with a title, assignee, and due date.
3. View active chores with their assignee and due date.
4. Mark chores complete and view them in a separate completed section.

## Status

Planning is complete. Implementation has not started.
